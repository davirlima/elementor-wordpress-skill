# Codex runtime

Resolve paths from the installed skill directory, even when the user's working directory is a different project. Use the available tool discovery interface to find the Elementor MCP server and prove it with a read call for the requested site. A config-file lookup is a convenience, not proof that the server is live or absent.

For connection setup, follow `references/setup.md` and the client prompt generated by Elementor. Respect filesystem and network sandbox permissions; request the narrowest required escalation when a necessary command fails due to the sandbox. Configuration changes outside writable roots may require approval. Reload or restart the session when needed for newly configured tools to appear. Do not expose credentials in command output or responses.
