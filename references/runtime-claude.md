# Claude Code runtime

Resolve paths from the installed skill directory, even when the user's working directory is a different project. Discover the site's Elementor MCP tools and prove the connection with a read call. A config-file lookup is a convenience, not proof that the server is live or absent.

For connection setup, follow `references/setup.md` and Elementor's generated client prompt. Use the available Claude Code permission mechanisms for network and configuration access. Reconnect with `/mcp` or restart if needed. Do not expose credentials in command output or responses; headers passed to `claude mcp add` may be stored in plain text in the client configuration.
